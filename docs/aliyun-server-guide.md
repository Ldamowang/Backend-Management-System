# 阿里云服务器选型与预算指南

> 针对 Admin Management System（Spring Boot + Vue 3 + MySQL + Redis）项目的阿里云部署方案。
> 价格数据更新时间：2026 年 4 月

---

## 一、结论：推荐方案

根据项目特点（单体 Spring Boot + 前端 + MySQL + Redis），推荐以下三档方案：

| 方案 | 适用场景 | 首年总预算 |
|------|---------|-----------|
| **方案 A：入门级** | 个人学习、内部演示 | **~350 元/年** |
| **方案 B：标准级（推荐）** | 小团队生产使用（<50 人） | **~1,300 元/年** |
| **方案 C：企业级** | 正式生产环境（50+ 用户） | **~6,000 元/年** |

---

## 二、方案详解

### 方案 A：入门级（个人/演示）

> 适用场景：个人开发测试、内部演示、功能验证

#### 服务器配置

| 项目 | 选型 | 说明 |
|------|------|------|
| 实例规格 | ECS 通用算力型 u1 | 性价比最高的入门选择 |
| CPU / 内存 | 2 核 4G | Spring Boot + MySQL + Redis 勉强够用 |
| 系统盘 | 80G ESSD Entry | 系统 + 应用 + 数据库 |
| 带宽 | 5M 固定带宽 | 后台管理系统足够 |
| 操作系统 | Alibaba Cloud Linux 3 | 免费，阿里云深度优化 |
| 地域 | 华北 2（北京）/ 华东 1（杭州） | 国内主流地域 |

#### JVM 调优建议（4G 内存分配）

```
Spring Boot JVM:  -Xmx1g -Xms512m
MySQL:            ~1.2G（innodb_buffer_pool_size=768M）
Redis:            ~256M（maxmemory 256mb）
系统 + Nginx:     ~500M
剩余缓冲:         ~1G
```

#### 费用明细

| 项目 | 费用 | 备注 |
|------|------|------|
| ECS u1 (2核4G) | 199 元/年 | 活动价，续费同价 |
| 域名 (.com) | 85 元/年 | 首年可能有优惠（35 元起） |
| SSL 证书 | 0 元 | 免费版个人测试证书（每年 20 张） |
| **合计** | **~284 元/年** | 不含域名首年优惠 |

#### 限制与风险

- 4G 内存运行全套服务偏紧张，高峰期可能 OOM
- 单机部署无高可用，宕机需手动恢复
- 不适合正式对外服务

---

### 方案 B：标准级（推荐）

> 适用场景：小团队（<50 人）日常使用的生产环境

#### 服务器配置

| 项目 | 选型 | 说明 |
|------|------|------|
| 实例规格 | ECS 通用算力型 u2a | 平衡性能与成本 |
| CPU / 内存 | 4 核 8G | 运行 Docker Compose 全套服务 |
| 系统盘 | 40G ESSD | 操作系统 |
| 数据盘 | 100G ESSD | 数据库 + 日志（与系统盘分离） |
| 带宽 | 5M 固定带宽 | 后台管理系统充足 |
| 操作系统 | Alibaba Cloud Linux 3 | 免费 |
| 地域 | 华北 2（北京） | 国内主流 |

#### 资源分配（8G 内存）

```
Docker 容器资源分配：
├── Spring Boot:    -Xmx2g -Xms1g      (~2.5G 含非堆)
├── MySQL 8.0:      innodb_buffer_pool=2G (~2.5G)
├── Redis 7:        maxmemory 512mb      (~600M)
├── Nginx:                               (~100M)
└── 系统 + 缓冲:                          (~2.3G)
```

#### 费用明细

| 项目 | 费用 | 备注 |
|------|------|------|
| ECS u2a (4核8G) | 898 元/年 | 活动价 |
| 数据盘 100G ESSD | ~180 元/年 | PL0 级别 |
| 域名 (.com) | 85 元/年 | 续费 95 元/年 |
| SSL 证书 | 0 元 | 免费证书 / Let's Encrypt |
| **合计** | **~1,163 元/年** | |

#### 优势

- 8G 内存运行 Docker Compose 全套服务游刃有余
- 数据盘独立，方便备份和扩容
- 性价比极高，千元级年费

### 方案 C：企业级（生产环境）

> 适用场景：正式生产环境，需要高可用、数据安全

#### 架构升级：计算与存储分离

将 MySQL 和 Redis 交给阿里云托管服务，ECS 只跑应用。

| 项目 | 选型 | 说明 |
|------|------|------|
| **ECS 应用服务器** | 计算型 c9i 或 u2a (4核8G) | 只运行 Spring Boot + Nginx |
| **RDS MySQL** | 基础系列倚天版 2核4G | 托管数据库，自动备份 |
| **Redis** | 云数据库 Redis 1G | 托管缓存，主从高可用 |
| 系统盘 | 40G ESSD | |
| 带宽 | 5-10M 固定带宽 | |
| 操作系统 | Alibaba Cloud Linux 3 | |

#### 费用明细

| 项目 | 费用 | 备注 |
|------|------|------|
| ECS u2a (4核8G) | 898 元/年 | 只跑应用服务 |
| RDS MySQL (2核4G 基础版) | ~228 元/年 | 倚天版活动价 |
| 云 Redis (1G 标准版) | ~400 元/年 | 单副本/主从 |
| 域名 (.com) | 85 元/年 | |
| SSL 证书（付费版） | ~82 元/年 | DV 单域名入门版 |
| OSS 对象存储 | ~50 元/年 | 文件/导出存储（按量） |
| **合计** | **~1,743 元/年** | |

如选 RDS 高可用版（主备双节点）：

| 项目 | 费用 | 备注 |
|------|------|------|
| RDS MySQL (2核4G 高可用) | ~3,888 元/年 | 主备自动切换 |
| 其他同上 | ~1,515 元/年 | |
| **合计** | **~5,403 元/年** | |

#### 托管服务的优势

| 对比项 | 自建（方案 B） | 托管（方案 C） |
|--------|---------------|---------------|
| 数据备份 | 需自己写脚本 | 自动备份，一键恢复 |
| 高可用 | 单点故障 | 主备自动切换 |
| 安全更新 | 手动升级 | 自动安全补丁 |
| 监控告警 | 需自己搭建 | 内置监控 + 告警 |
| 性能调优 | 需要 DBA 经验 | 提供优化建议 |
| 运维成本 | 高 | 低 |

## 四、省钱攻略

### 4.1 新用户优惠

- 新用户首购 ECS 价格远低于续费价，**建议用新账号购买**
- 经济型 e 实例 2核2G 仅 **99 元/年**（学习用途极佳）
- u1 实例 2核4G 仅 **199 元/年**

### 4.2 长期锁价

- **3 年付打 3.9 折**（比年付累计省 40%+），适合确定长期使用的场景
- 活动截止 2027 年 3 月 31 日，经济型 e / u1 实例可以每年以活动价续费 1 次

### 4.3 域名省钱

- `.com` 首年注册活动价低至 35 元（正常 85 元）
- `.cn` 域名注册 38 元/年，续费 42 元/年，比 `.com` 便宜
- 域名转入（从其他平台）也有优惠

### 4.4 SSL 证书省钱

- **免费证书**：每个账号每年可申请 20 张免费 DV 证书（个人测试证书）
- **Let's Encrypt**：完全免费，自动续期，生产环境够用
- 付费证书起步价 82 元/年（DV 单域名入门版）

### 4.5 替代方案：数据库不用 RDS

如果预算有限，方案 B（全部自建在一台 ECS 上）是最佳性价比选择。只需要：
- 配好自动备份脚本（crontab + mysqldump）
- 定期将备份文件同步到 OSS（几毛钱/月）

## 五、购买流程

### 5.1 ECS 服务器购买

1. 访问 [阿里云 ECS 控制台](https://ecs.console.aliyun.com)
2. 选择「创建实例」
3. 关键配置选择：

| 步骤 | 选项 | 推荐值 |
|------|------|--------|
| 付费模式 | 包年包月 | 年付最划算 |
| 地域 | 华北 2（北京） | 国内访问快 |
| 实例规格 | 通用算力型 u2a | 4核8G（方案B） |
| 镜像 | Alibaba Cloud Linux 3 | 免费 + 优化 |
| 存储 | 系统盘 40G ESSD + 数据盘 100G ESSD | 分离存储 |
| 网络 | 默认 VPC | 自动创建 |
| 带宽 | 按固定带宽 5Mbps | |
| 安全组 | 开放 22/80/443 | |

### 5.2 购买后的初始化

```bash
# 1. SSH 连接服务器
ssh root@<your-server-ip>

# 2. 更新系统
yum update -y   # Alibaba Cloud Linux / CentOS
# 或
apt update && apt upgrade -y   # Ubuntu

# 3. 安装 Docker
curl -fsSL https://get.docker.com | sh
systemctl enable docker && systemctl start docker

# 4. 安装 Docker Compose
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" \
  -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 5. 验证安装
docker --version
docker-compose --version

# 6. 创建数据目录（挂载数据盘）
mkfs.ext4 /dev/vdb              # 格式化数据盘
mkdir -p /data
mount /dev/vdb /data
echo '/dev/vdb /data ext4 defaults 0 0' >> /etc/fstab

# 7. 配置防火墙
# 阿里云安全组已控制，服务器内部防火墙可选配置
```

### 5.3 域名购买与备案

1. 访问 [万网域名注册](https://wanwang.aliyun.com/domain)
2. 搜索并注册域名
3. **ICP 备案**（国内服务器必须）：
   - 在阿里云 [备案中心](https://beian.aliyun.com) 提交
   - 准备材料：身份证/营业执照、域名证书、真实性核验
   - 周期：约 5-15 个工作日
   - **未备案的域名无法解析到国内服务器的 80/443 端口**

### 5.4 SSL 证书申请

```bash
# 方式一：阿里云免费证书
# 控制台 → 数字证书管理服务 → 免费证书 → 申请

# 方式二：Let's Encrypt（推荐，免费 + 自动续期）
# 在服务器上执行：
yum install -y certbot
certbot certonly --standalone -d admin.yourdomain.com
# 证书位置：/etc/letsencrypt/live/admin.yourdomain.com/

# 自动续期
echo "0 3 * * 1 certbot renew --quiet" | crontab -
```

## 六、重要提醒

### 6.1 ICP 备案（必须）

使用**国内服务器**部署网站，域名**必须完成 ICP 备案**，否则：
- 80/443 端口会被阿里云拦截
- 无法正常提供 HTTP/HTTPS 服务

备案流程约 5-15 个工作日，建议提前准备。

### 6.2 安全组配置

购买 ECS 后，在安全组中只开放必要端口：

| 端口 | 协议 | 授权对象 | 用途 |
|------|------|---------|------|
| 22 | TCP | 你的 IP | SSH 管理 |
| 80 | TCP | 0.0.0.0/0 | HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS |

**不要开放** 3306（MySQL）、6379（Redis）、8080（Spring Boot）给公网。

### 6.3 数据盘挂载

- 系统盘只放操作系统和应用
- 数据盘放 MySQL 数据、Redis 持久化、日志文件
- 数据盘支持在线扩容，系统盘扩容需停机

### 6.4 快照与备份

- 开启 ECS 自动快照策略（免费额度内）
- 数据库定时备份到 OSS
- 重要操作前手动创建快照
