# 验收 Checklist 模板

> 每个功能模块在交付前需完成以下验收项

## 模块名称：[填写模块名]

### 功能验收

- [ ] 所有需求点已实现
- [ ] 正向流程测试通过
- [ ] 异常流程测试通过（空值、非法输入、超长文本）
- [ ] 边界条件测试通过

### 权限验收

- [ ] admin 角色可正常操作
- [ ] user 角色按权限矩阵限制
- [ ] 无权限用户看不到对应按钮
- [ ] 直接调用 API 也返回 403

### UI/UX 验收

- [ ] 页面布局与原型一致
- [ ] 表单校验提示友好
- [ ] Loading 状态正确显示
- [ ] 空数据状态正确显示
- [ ] 操作成功/失败有 Toast 提示

### 数据验收

- [ ] 数据正确写入数据库
- [ ] 分页数据正确（total/page/size）
- [ ] 审计字段自动填充（created_by/created_time/updated_by/updated_time）
- [ ] 逻辑删除正确（deleted=1）

### 安全验收

- [ ] 未登录无法访问
- [ ] 接口参数已校验
- [ ] 无 SQL 注入风险
- [ ] 无 XSS 风险
