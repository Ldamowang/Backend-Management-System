# PRD v1.0 - 后台管理系统

> 状态：草稿

> 作者：产品经理（待指定）

## 1. 产品概述

企业级后台管理系统，提供用户管理、角色管理、菜单管理、系统配置、日志审计等核心功能，基于 RBAC 权限模型控制访问。

## 2. 目标用户

- **超级管理员**：系统维护人员，拥有全部权限
- **普通用户**：业务操作人员，拥有部分查看权限
- （后续可扩展更多角色）

## 3. 功能需求

### 3.1 认证模块

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 登录 | 用户名 + 密码登录，返回 JWT Token | P0 |
| 登出 | 清除 Token，Redis 黑名单 | P0 |
| Token 刷新 | Access Token 过期自动刷新 | P0 |
| 获取用户信息 | 登录后获取当前用户信息、角色、权限 | P0 |

**验收标准：**
- [ ] 正确用户名密码登录成功，返回 accessToken + refreshToken
- [ ] 错误密码返回明确错误提示
- [ ] 禁用用户无法登录
- [ ] Token 过期后自动使用 refreshToken 续期
- [ ] refreshToken 过期后跳转登录页

### 3.2 用户管理

| 功能 | 描述 | 权限标识 | 优先级 |
|------|------|---------|--------|
| 用户列表 | 分页查询、条件搜索 | sys:user:list | P0 |
| 新增用户 | 填写用户信息并分配角色 | sys:user:add | P0 |
| 编辑用户 | 修改用户信息 | sys:user:edit | P0 |
| 删除用户 | 逻辑删除 | sys:user:delete | P0 |
| 状态切换 | 启用/禁用 | sys:user:edit | P1 |
| 重置密码 | 管理员重置 | sys:user:edit | P1 |
| 数据导出 | 导出 Excel | sys:user:export | P2 |

**验收标准：**
- [ ] 分页展示用户列表，支持按用户名/手机号/状态搜索
- [ ] 新增用户时用户名唯一校验
- [ ] 删除用户为逻辑删除（deleted=1）
- [ ] 无权限用户看不到新增/编辑/删除按钮

### 3.3 角色管理

| 功能 | 描述 | 权限标识 | 优先级 |
|------|------|---------|--------|
| 角色列表 | 分页查询 | sys:role:list | P0 |
| 新增角色 | 填写角色信息 | sys:role:add | P0 |
| 编辑角色 | 修改角色信息 | sys:role:edit | P0 |
| 删除角色 | 逻辑删除 | sys:role:delete | P0 |
| 分配权限 | 为角色分配菜单权限 | sys:role:edit | P0 |

**验收标准：**
- [ ] 分配权限使用树形勾选，展示所有菜单和按钮
- [ ] 已分配用户的角色不可删除（或提示确认）
- [ ] 角色标识（roleKey）唯一

### 3.4 菜单管理

| 功能 | 描述 | 权限标识 | 优先级 |
|------|------|---------|--------|
| 菜单列表 | 树形展示 | sys:menu:list | P0 |
| 新增菜单 | 目录/页面/按钮 | sys:menu:add | P0 |
| 编辑菜单 | 修改菜单信息 | sys:menu:edit | P0 |
| 删除菜单 | 有子菜单时禁止删除 | sys:menu:delete | P0 |

### 3.5 系统配置

| 功能 | 描述 | 权限标识 | 优先级 |
|------|------|---------|--------|
| 配置列表 | 展示系统参数 | sys:config:list | P1 |
| 编辑配置 | 修改参数值 | sys:config:edit | P1 |

### 3.6 日志管理

| 功能 | 描述 | 权限标识 | 优先级 |
|------|------|---------|--------|
| 操作日志 | 查看系统操作记录 | sys:log:list | P1 |
| 登录日志 | 查看登录记录 | sys:log:list | P1 |

### 3.7 仪表盘

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 统计卡片 | 用户总数、角色总数、今日登录、今日操作 | P1 |
| 趋势图表 | ECharts 登录/操作趋势 | P2 |

### 3.8 个人中心

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 查看个人信息 | 展示当前用户信息 | P0 |
| 修改个人信息 | 修改昵称、邮箱、手机号 | P1 |
| 修改密码 | 验证旧密码后修改 | P1 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 < 2s；API 响应 < 500ms；支持 100 并发用户 |
| 安全 | JWT 认证；RBAC 权限；XSS 防护；SQL 注入防护；接口限流 |
| 兼容性 | Chrome 90+、Firefox 90+、Edge 90+、Safari 15+ |
| 可用性 | Docker 一键部署；支持水平扩展 |
| 测试 | 单元测试覆盖率 >= 80%；E2E 覆盖核心路径 |

## 5. 数据模型

详见 `sql/schema.sql`，核心表：

- `sys_user` - 用户表
- `sys_role` - 角色表
- `sys_menu` - 菜单权限表
- `sys_user_role` - 用户角色关联
- `sys_role_menu` - 角色菜单关联
- `sys_operation_log` - 操作日志
- `sys_login_log` - 登录日志
- `sys_config` - 系统配置
