# P0.4 并发登录控制实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 限制同一账号并发登录会话数，支持踢旧/拒新策略，被踢出用户通过 WebSocket 实时通知。

**Architecture:** 利用 Redis Sorted Set 记录每个用户的活跃会话（score=登录时间戳，member=token），登录时检查会话数并执行配置的冲突策略。被踢出的 token 加入黑名单，同时通过 WebSocket 推送下线通知。

**Tech Stack:** Redis Sorted Set, Spring Security, WebSocket (STOMP), Vue 3

## Task 2: 重构在线用户存储为 Sorted Set

**Files:**
- Modify: `admin-backend/src/main/java/com/iflytek/admin/modules/system/service/impl/OnlineUserServiceImpl.java`

- [ ] **Step 1: 重构 OnlineUserServiceImpl**

核心变更：每个用户的会话使用 Sorted Set 存储，同时保留单个 token 详情的 Hash。

在 `OnlineUserServiceImpl.java` 中添加方法：

```java
/**
 * 记录在线用户会话（替代原有的简单 set）
 */
public void addSession(Long userId, String token, Map<String, Object> userInfo) {
    String sessionsKey = CacheConstants.USER_SESSIONS_PREFIX + userId;
    String tokenKey = CacheConstants.ONLINE_USER_PREFIX + token;

    // 将 token 添加到用户会话集合（score = 当前时间戳）
    redisTemplate.opsForZSet().add(sessionsKey, token, System.currentTimeMillis());
    redisTemplate.expire(sessionsKey, Duration.ofDays(7));

    // 存储 token 详情（保持原有逻辑）
    redisTemplate.opsForValue().set(tokenKey, userInfo,
            Duration.ofMillis(jwtUtil.getAccessTokenExpiration()));
}

/**
 * 移除会话
 */
public void removeSession(Long userId, String token) {
    String sessionsKey = CacheConstants.USER_SESSIONS_PREFIX + userId;
    redisTemplate.opsForZSet().remove(sessionsKey, token);
    redisTemplate.delete(CacheConstants.ONLINE_USER_PREFIX + token);
}

/**
 * 获取用户当前会话数
 */
public long getSessionCount(Long userId) {
    String sessionsKey = CacheConstants.USER_SESSIONS_PREFIX + userId;
    Long count = redisTemplate.opsForZSet().zCard(sessionsKey);
    return count != null ? count : 0;
}

/**
 * 踢出最旧的会话
 */
public String kickOldestSession(Long userId) {
    String sessionsKey = CacheConstants.USER_SESSIONS_PREFIX + userId;
    // 获取 score 最小的（最旧的）
    var oldest = redisTemplate.opsForZSet().rangeWithScores(sessionsKey, 0, 0);
    if (oldest != null && !oldest.isEmpty()) {
        var entry = oldest.iterator().next();
        String oldToken = (String) entry.getValue();
        // 移除会话
        removeSession(userId, oldToken);
        // 加入黑名单
        redisTemplate.opsForValue().set(
                CacheConstants.TOKEN_BLACKLIST_PREFIX + oldToken, "kicked",
                Duration.ofMillis(jwtUtil.getAccessTokenExpiration()));
        return oldToken;
    }
    return null;
}
```

同时修改原有的 `kickOut(String token)` 方法，增加从 Sorted Set 中移除的逻辑：

```java
@Override
public void kickOut(String token) {
    // 从 token 详情中获取 userId
    Object userInfo = redisTemplate.opsForValue().get(CacheConstants.ONLINE_USER_PREFIX + token);
    if (userInfo instanceof Map) {
        Long userId = ((Number) ((Map<?, ?>) userInfo).get("userId")).longValue();
        removeSession(userId, token);
    } else {
        redisTemplate.delete(CacheConstants.ONLINE_USER_PREFIX + token);
    }
    // 加入黑名单
    redisTemplate.opsForValue().set(
            CacheConstants.TOKEN_BLACKLIST_PREFIX + token, "kicked",
            Duration.ofMillis(jwtUtil.getAccessTokenExpiration()));
}
```

**Files:**

- [ ] **Step 1: 在 AuthServiceImpl 中添加会话控制逻辑**

注入依赖（如果未注入）：


在 login 方法中，生成 Token 之后、记录在线用户之前，添加会话控制：

```java
// === 会话并发控制 ===
int maxSessions = getConfigInt("login.max-sessions", CacheConstants.DEFAULT_MAX_SESSIONS);
String conflictPolicy = getConfigString("login.conflict-policy", "kick_old");

long currentSessions = onlineUserService.getSessionCount(user.getId());
if (currentSessions >= maxSessions) {
    if ("reject_new".equals(conflictPolicy)) {
        throw new BusinessException(ResultCode.BAD_REQUEST.getCode(), "您的账号已在其他设备登录，不允许重复登录");
    }
    // kick_old: 踢出最旧的会话
    while (onlineUserService.getSessionCount(user.getId()) >= maxSessions) {
        String kickedToken = onlineUserService.kickOldestSession(user.getId());
        if (kickedToken != null) {
            // 通过 WebSocket 通知被踢出的用户
            try {
                messagingTemplate.convertAndSendToUser(
                        user.getUsername(),
                        "/queue/kick",
                        Map.of("message", "您的账号在其他设备登录，当前会话已被强制下线")
                );
            } catch (Exception ignored) {
                // WebSocket 推送失败不影响登录
            }
        } else {
            break;
        }
    }
}

// 记录新会话（替代原有的 Redis set 逻辑）
Map<String, Object> onlineInfo = new HashMap<>();
onlineInfo.put("userId", user.getId());
onlineInfo.put("username", user.getUsername());
onlineInfo.put("nickname", user.getNickname());
onlineInfo.put("loginTime", LocalDateTime.now().toString());
onlineUserService.addSession(user.getId(), accessToken, onlineInfo);
```

添加辅助方法：
```java
private int getConfigInt(String key, int defaultValue) {
    // 从 sys_config 或 Redis 缓存获取配置值
    try {
        Object val = cacheService.get(CacheConstants.CONFIG_PREFIX + key, String.class);
        if (val != null) return Integer.parseInt(val.toString());
    } catch (Exception ignored) {}
    return defaultValue;
}

private String getConfigString(String key, String defaultValue) {
    try {
        Object val = cacheService.get(CacheConstants.CONFIG_PREFIX + key, String.class);
        if (val != null) return val.toString();
    } catch (Exception ignored) {}
    return defaultValue;
}
```
